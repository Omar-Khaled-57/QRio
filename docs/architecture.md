## Entry points and process model

1. [`../index.html`](../index.html) mounts `#app` and loads `/src/main.ts`.
2. [`../src/main.ts`](../src/main.ts) creates the Vue app, imports global
   styles, and mounts [`../src/App.vue`](../src/App.vue).
3. `App.vue` holds the active tab (`create`, `library`, `settings`), renders
   `NavBar`, the selected tab component, and `Toast`.

This is a static client-side SPA. There is no Node server at runtime, no API
layer, and no Rust/native process. The service worker generated by
`vite-plugin-pwa` is the only background process, and it is configured with
`registerType: 'autoUpdate'`.

## Data and state flow

1. **Content entry.** `TabCreate.vue` binds per-type fields to local refs and
   watches them, joining values with `\n` into `config.value.content`.
   `buildQrContent()` in `useQR.ts` converts that string into the final QR
   payload (`mailto:`, `sms:`, `WIFI:`, vCard, `geo:`, or pass-through).
2. **Shared state.** `config` is a single module-level `Ref<QRConfig>` imported
   by the form, preview, settings, library, and `App.vue`. `PreviewPanel.vue`
   watches it deeply and redraws the on-screen canvas at 280 px.
3. **Export.** `downloadPng()` calls `exportFullImage(config.exportSize)`,
   which re-renders the QR at the chosen size, then composites a brand header,
   optional frame banners, and the center icon onto a second canvas. The result
   is a PNG data URL used for download, clipboard, and print.
4. **Persistence.** `saveToLib()` serializes the whole `QRConfig` as a JSON
   string inside a `QRSaved` record `{ id?, label, type, config, ts }` and adds
   it to IndexedDB. `TabLibrary.vue` parses that JSON back into `config` when a
   saved QR is reopened.
5. **Auto-save.** With `autoSave` enabled, `App.vue` writes the current config
   to the same store on `beforeunload`. This is separate from the
   `saveExport()` placeholder in `useDB.ts`.

## Storage and integration boundaries

| Boundary | Detail |
| --- | --- |
| IndexedDB | Database `qrio`, store `library`, version 2, auto-increment key `id` — [`../src/composables/useDB.ts`](../src/composables/useDB.ts) |
| localStorage | `qrio_lang`, `qrio_theme`, `qrio-uploaded-icons` — see [configuration](./configuration.md) |
| Network | No application API calls. `index.html` requests Nunito from Google Fonts; the local Cairo font file lives under `public/font/` |
| Tooling config | [`../opencode.json`](../opencode.json) holds an OpenRouter provider entry for the coding tool with a placeholder key. It is not imported by the app bundle and is not a runtime secret |
